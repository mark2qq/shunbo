顺播 shunbo 安装说明
====================

欢迎安装「顺播 shunbo」—— 一款聚合多源、无感换源、支持跨端续播的
桌面/移动视频播放软件。

本安装包为自用侧载包，未做代码签名。Windows 可能在安装或首次运行时
提示「未知发布者」，属预期行为，选择「仍要运行 / 允许」即可。

安装位置
--------
默认安装到当前用户的「本地应用数据」目录（%LOCALAPPDATA%\Programs\Shunbo），
不会写入系统目录，也不需要管理员权限，卸载时无系统级残留。

包含内容
--------
安装包内仅含程序本体，以及随包分发的媒体解码依赖（libmpv / media_kit 的
Windows 原生动态库）。软件本身不含任何视频内容源，频道与线路由用户在
应用内自行导入与配置。

使用提示
--------
- 频道号遵循「央视 1 起、卫视 101 起、地方台 201 起」的固定编排，可在频道
  列表中按号快速定位。
- 自动切台只在同分组内向后兜底，不会跨组乱跳。
- 每个频道会记住上一次播放流畅的线路，下次切换到该频道时直接复用。

隐私与网络
----------
软件仅在用户主动导入源配置、或播放所选线路时发起网络请求；不会在后台
上传任何本地数据。导入的源配置仅保存在本机用户目录下。

如需卸载，请在系统「应用」设置中找到「顺播 shunbo」并卸载即可。

感谢使用顺播 shunbo。
