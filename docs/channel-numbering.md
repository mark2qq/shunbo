**央视一套 = 数字编号 1**（需求硬性要求）。央视 1–17 依次对应 1–17；`CCTV-5+`（体育赛事）= 18；`CCTV 4K`（超高清）= 19；`CGTN` = 20；`CGTN 纪录` = 21；`中国教育 1–4` = 22–25；`CCTV-8K`（8K 超高清）= 26。

## 二、频道分类与内容来源的对应关系

分类是**可叠加**的：一个台有「主分类」（按来源归属）与「内容分类」（按节目类型）。频道栏的分类过滤用的是两者的并集。

| 分类 | 收录的内容来源 | 说明 |
| --- | --- | --- |
| 全部 | 全部 | 默认视图 |
| 央视频道 | 央视 | CCTV / CGTN / 中国教育 1–4 |
| 卫视频道 | 卫视 | 省级卫视 |
| 地方频道 | 地方 | 省市地方台（按 IP 定位城市过滤） |
| 新闻 | 央视 + 卫视 + 地方 | 内容分类，与主分类叠加 |
| 体育 | 央视 + 卫视 + 地方 | 内容分类，与主分类叠加 |
| 影视 | 央视 + 卫视 + 地方 | 内容分类，与主分类叠加 |
| 少儿 | 央视 + 卫视 + 地方 | 内容分类，与主分类叠加 |
| 纪实 | 央视 + 全网其它视频源 | 内容分类，与主分类叠加 |
| 生活 | 央视 + 卫视 + 地方 | 内容分类，与主分类叠加 |

> 需求原文：「新闻、少儿、体育三个分类频道的内容来源覆盖央视、卫视、地方三类频道；纪实分类频道的内容来源为央视及全网其它视频源；除上述已列来源之外的其它来源视频统一归入『其它』频道。」

## 四、遥控器数字输入（Android TV）

* **逐位累积**：按 `1` 立刻切到 CCTV-1；继续按 `0` 会在 1.5 秒内等成 `10`；超时未继续按就把已输入的数字当成完整编号提交。
* **确认键立即提交**：按「确认 / OK」不用等超时。
* **返回键取消**：按「返回 / ESC」放弃本次输入。
* 界面上给出「**编号 + 台名**」浮层，逐字确认输到了哪一步、跳到了哪个台。
* 数字输入走的是与点台**完全相同**的调台流程（`LiveController.tuneByNumber` → `tune`），不另开一条播放路径。
* 安卓清单已声明 `leanback` / `touchscreen` 非必需并注册 `LEANBACK_LAUNCHER`，电视端可安装、可被启动器检索。
