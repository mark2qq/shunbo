顺播 shunbo 0.1.0（Windows 桌面版）
=====================================

这是一份自用侧载包，未做代码签名，安装时 Windows 可能提示「未知发布者」，
选择「仍要运行」即可。

安装位置
--------
per-user 安装（不弹 UAC）：%LOCALAPPDATA%\Programs\Shunbo
开始菜单与桌面快捷方式可自行勾选。

这个版本能做什么
----------------
- 多源聚合搜索、选源、选集、播放（Windows 端用随包的 libmpv，硬解，能出画面）。
- 无感换源：换源时按源画像（集数偏移 / 广告插入）重新映射位置，内容进度不丢。
- 播放中进度落盘 + 片尾判定 + 自动连播下一集（可在播放页关闭）。
- 断点续播；跨端续播同步（当前用共享目录快照传输，账号云仍在规划中）。
- DLNA 投屏：局域网发现真实设备，失败/掉线自动切回本机并保住进度。
- 源配置导入（粘贴 / 本地文件 / https 链接）与导出备份，全部经过安全白名单。
- 诊断日志：JSONL 落盘，用于定位「哪一环断了」。

数据放在哪
----------
进度、配置、引导状态、诊断日志都在：%LOCALAPPDATA%\Shunbo\
（Android 版在应用私有缓存目录，卸载即清。）
卸载程序不会删这些文件，重装后「继续观看」仍然有效；要彻底清空请手动删除该目录。

明确不做
--------
- 不内置、不缓存、不分发任何影视内容；所有地址来自使用者自行导入的第三方源。
- 不含直播频道表 / EPG / 时移回看（设计中，未实现）。
- 不含倍速、多音轨、外挂字幕、画面比例切换（设计中，未实现）。
